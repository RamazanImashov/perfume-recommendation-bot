# Perfume Bot на aiogram 3

Личный Telegram-бот для подбора аромата под погоду, мероприятие, обстоятельства и описание образа.

## Что умеет

- получает погоду через Open-Meteo;
- принимает геолокацию Telegram или город текстом;
- спрашивает мероприятие, обстоятельства и желаемый эффект;
- принимает описание образа текстом;
- парсит одежду в теги;
- выдает топ-3 аромата с объяснением, количеством пшиков и местом нанесения.

## Бесплатные API

- Open-Meteo Forecast API — погода, без ключа.
- Open-Meteo Geocoding API — поиск координат по городу, без ключа.
- Telegram Bot API — через aiogram 3.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` вставь токен от BotFather:

```env
BOT_TOKEN=123456:ABCDEF
OWNER_ID=
```

`OWNER_ID` необязателен. Если хочешь закрыть бота только для себя, укажи свой Telegram user ID.

## Запуск

```bash
python main.py
```

## Как пользоваться

1. Нажми `Подобрать аромат`.
2. Отправь геолокацию или город.
3. Выбери мероприятие.
4. Напиши образ текстом.
5. Выбери обстоятельства.
6. Выбери эффект.
7. Получи топ-3.

Пример описания образа:

```text
Черные широкие джинсы, белые кроссовки, темно-зеленое поло, кожаная куртка.
```

## Где менять базу ароматов

Файл:

```text
app/data/perfumes.py
```

Каждый аромат хранится как словарь с тегами, погодным диапазоном, назначением, эффектами, количеством пшиков и ограничениями.

## Важное замечание

Это rule-based MVP. Он не использует платные AI API. Если хочешь, можно позже добавить анализ фото образа локальной моделью, но для первой версии текстовое описание надежнее.
